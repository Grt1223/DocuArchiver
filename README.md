## English Version

A powerful browser extension designed to help you organize and manage downloaded files. Say goodbye to a messy downloads folder by automatically routing files from specific websites to designated directories\!

### ✨ Features

  * **🧠 Smart Memory Archiving:** Automatically remembers the relationship between specific websites and their corresponding download folders.
  * **📁 Auto-Routing:** Future downloads from a recognized website will be automatically routed to your preset directory. No more manual sorting\!
  * **🌍 Multi-Language Support:** Available in 6 languages, adjusting seamlessly to your browser settings:
      * English (`en`)
      * Traditional Chinese / 繁體中文 (`zh_TW`)
      * Japanese / 日本語 (`ja`)
      * Korean / 한국어 (`ko`)
      * Spanish / Español (`es`)
      * Arabic / العربية (`ar`)
  * **⚡ Lightweight & Fast:** Extremely small footprint, consuming minimal browser resources.
  * **🔒 Privacy Focused:** We do not collect, store, or transmit your personal data or download history.

### 🚀 Installation

**Method 1: Install from Chrome Web Store (Recommended)**

1.  Visit the [DocuArchiver Chrome Web Store page](https://chromewebstore.google.com/detail/%E8%BB%9F%E9%AB%94%E5%B7%A5%E7%A8%8B%E8%B3%87%E6%96%99%E4%B8%8B%E8%BC%89%E6%AD%B8%E6%AA%94%E5%B7%A5%E5%85%B7/gibhmkanemilpnjfhgojaojannbanifc).
2.  Click **"Add to Chrome"**.
3.  Confirm the installation and start organizing your downloads\!

**Method 2: Developer Installation (Local)**

1.  Clone this repository: `git clone https://github.com/Grt1223/docu-archiver.git`
2.  Open Chrome and navigate to `chrome://extensions/`.
3.  Enable **"Developer mode"** in the top right corner.
4.  Click **"Load unpacked"** and select the cloned project folder.

### 💡 Usage

1.  Pin the extension to your Chrome toolbar.
2.  **First Download Binding:** When you download a file from a new website, select the target folder where you want to save it. The extension will remember this choice.
3.  **Auto-Archiving:** The next time you download a file from the same website, DocuArchiver will automatically save it to that specific folder.
4.  **Manage Rules:** Click the extension icon to view, edit, or delete your saved routing rules.

## 繁體中文版

一款強大的瀏覽器文件歸檔、整理與管理工具。協助您從瀏覽器快速儲存、分類及存取重要檔案，讓您的下載資料夾不再像無底洞，徹底告別「下載地獄」！

### ✨ 核心功能

  * **🧠 智慧記憶歸檔**：自動記憶特定網站與對應下載資料夾的關聯。
  * **📁 自動分類整理**：後續從同網站下載的檔案將自動路由至指定目錄，省去手動整理的時間。
  * **🌍 多國語言支援**：內建 6 種語言介面，自動適配您的瀏覽器語系：
      * 繁體中文 (`zh_TW`)
      * English (`en`)
      * 日本語 (`ja`)
      * 한국어 (`ko`)
      * Español (`es`)
      * العربية (`ar`)
  * **⚡ 輕量無負擔**：極小體積，不佔用瀏覽器多餘資源，運行流暢。
  * **🔒 隱私安全**：不收集、不儲存、也不傳輸您的任何個人隱私數據與下載紀錄。

### 🚀 安裝方式

**方法一：從 Chrome 線上應用程式商店安裝（推薦）**

1.  前往 [Chrome Web Store 頁面](https://chromewebstore.google.com/detail/%E8%BB%9F%E9%AB%94%E5%B7%A5%E7%A8%8B%E8%B3%87%E6%96%99%E4%B8%8B%E8%BC%89%E6%AD%B8%E6%AA%94%E5%B7%A5%E5%85%B7/gibhmkanemilpnjfhgojaojannbanifc)。
2.  點擊右上方 **「加到 Chrome」** 按鈕。
3.  授權並確認安裝，即可開始使用。

**方法二：開發者本地安裝**

1.  將此專案 Clone 到本地：`git clone https://github.com/Grt1223/docu-archiver.git`
2.  開啟 Chrome 瀏覽器並輸入 `chrome://extensions/` 進入擴充功能管理頁面。
3.  開啟右上角的 **「開發人員模式」**。
4.  點擊左上角的 **「載入未封裝項目」**，並選擇剛剛 clone 下來的專案資料夾。

### 💡 使用說明

1.  將擴充功能固定於瀏覽器工具列。
2.  **首次下載綁定**：在任意網站進行第一次檔案下載時，指定您要歸檔的目錄路徑，系統會自動記憶。
3.  **自動歸檔生效**：設定完成後，未來只要從同一個網站下載任何檔案，系統將自動將檔案放入該指定的目錄中。
4.  **管理規則**：您可以隨時點擊擴充功能圖示，開啟面板來修改、新增或刪除網站與資料夾的綁定規則。
